Sistem AHP-TOPSIS untuk Penilaian Kinerja Keuangan
Sistem pengambilan keputusan berbasis web yang menggunakan metode AHP dan TOPSIS untuk menilai dan merangking kinerja keuangan perusahaan manufaktur.
Tentang Project
Project ini dikembangkan sebagai bagian dari program PKL di PT Pos Indonesia. Sistem ini membantu manajemen dalam mengevaluasi kinerja keuangan perusahaan secara objektif menggunakan metode Decision Support System.

Kriteria Penilaian

Profitabilitas - ROA, Tingkat Laba Operasional
Likuiditas - Rasio Lancar, Rasio Cepat
Solvabilitas - Total Utang/Nilai Bersih, Rasio Utang
Efisiensi - Tingkat Aset, Perputaran Aset

Teknologi

Python 3.8+
Flask
NumPy, Pandas
HTML, CSS, JavaScript

Instalasi
# Clone repository
git clone https://github.com/username/ahp-topsis-system.git
cd ahp-topsis-system

# Install dependencies
pip install -r requirements.txt

# Jalankan aplikasi
python aplikasi.py

Catatan
File Excel untuk upload data perusahaan harus memiliki kolom PERUSAHAAN dan semua sub-kriteria sesuai format yang ditentukan.
